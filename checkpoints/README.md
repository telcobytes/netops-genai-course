# Checkpoints

Three short projects spaced across the course. Bigger than a "Your turn",
smaller than the capstone — 15–25 minutes each.

Every checkpoint has the same three files:

- `starter.py` — the task, with `TODO` markers where your code goes
- `solution.py` — one working answer. Try it yourself first.
- `check.py` — run it to find out if you passed. Prints PASS or FAIL.

| # | After module | Task |
|---|---|---|
| 1 | 4 — RAG | Teach the retriever a new runbook and prove it ranks correctly |
| 2 | 7 — Workflow patterns | Build a dispatcher that routes five alarms and drops the noise |
| 3 | 10 — Eval | Design your own golden case and make it pass |

```bash
cd checkpoints/01_rag && python check.py
```
